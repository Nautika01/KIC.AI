# KIC.AI

「국부펀드 KIC, AI 에이전트 공모전」 참가 프로젝트 저장소입니다.

- 대회 페이지: https://daker.ai/public/hackathons/kic-ai-agent-competition
- 주최: 한국투자공사(KIC) / 운영: 데이콘(DAKER)
- 공모 주제: **투자 및 금융 업무 혁신을 위한 AI Agent 개발** (문제는 주제 범위 안에서 자유롭게 정의)
  - 예시: 기업·산업 동향 기반 투자 리서치 / 경쟁사·Peer Group 비교 분석 / 내부 문서·규정 검색 및 업무 자동화
- 단순 Q&A 챗봇이 아니라, 목적 이해 → 정보 탐색·분석 → 도구 활용 → 결과물 생성까지 하는 Agent 서비스가 목표

## 평가 기준

### 예선 전문가 평가 (100점)
| 항목 | 배점 | 내용 |
|---|---|---|
| 문제 정의 및 주제 적합성 | 20 | 투자·금융 업무의 실제 문제를 명확히 정의 |
| AI Agent 구성 및 설계 | 25 | Agent 역할, Workflow, Tool/API 활용 및 자율성 |
| 차별성 및 창의성 | 20 | 기존 서비스·단순 LLM 활용 대비 차별점 |
| 실현 가능성 | 20 | 본선 기간(약 3주) 내 MVP 구현 가능성 |
| 활용성 및 확장성 | 15 | 실제 활용 가능성과 향후 확장성 |

예선 상호 평가는 Elo 방식 페어 투표이며, 최소 투표 수를 채우지 않으면 득표도 반영되지 않음(No Vote, No Gain).

### 본선 발표 평가 (100점)
| 항목 | 배점 | 내용 |
|---|---|---|
| 문제 해결 및 활용 가치 | 20 | 실제 문제를 효과적으로 해결 |
| AI Agent 구현 완성도 | 25 | 계획·판단·Tool/API 활용을 안정적으로 수행 |
| AI Agent 기술성 | 20 | 단순 LLM 호출이 아닌 Agent 구조·기술적 차별성 |
| 결과의 신뢰성 | 15 | 근거·출처 확인, 오류·환각 대응 |
| 사용성 및 실용성 | 10 | 사용 편의성과 업무 적용 가능성 |
| 발표 및 질의응답 | 10 | 명확한 설명과 질의 대응 |

동점 시 ① 구현 완성도 ② 문제 해결 및 활용 가치 ③ 기술성 순.

## 규칙 요약
- 개인 또는 팀(최대 5인), 중복 참가 불가. 팀 빌딩 후 제출 전 팀장이 "팀으로 전환" 필수, 최종 제출은 팀장만 가능.
- 데이터셋 미제공 — 공개 데이터·적법한 외부 API 직접 선정. **데이터 출처, 수집일, 라이선스, 전처리 방법을 제출물에 반드시 기재.**
- 외부 데이터, 유료/무료 AI 모델·API 사용 허용 (라이선스·이용약관 준수, 사용한 외부 자원 출처 명시).
- 타 공모전 수상작·기존 공개/상용 결과물 그대로 제출 불가. 운영진이 코드 실행, API 이용 내역, 저장소 이력 등을 요청할 수 있음.
