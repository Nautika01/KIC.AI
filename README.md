# KIC.AI

「국부펀드 KIC, AI 에이전트 공모전」 참가 프로젝트 저장소입니다.

- 대회 페이지: https://daker.ai/public/hackathons/kic-ai-agent-competition

## 개요

- **주최:** 한국투자공사(KIC)
- **운영:** 데이콘(DAKER)
- **주제:** 투자 및 금융 업무 혁신을 위한 AI Agent 개발
  - 주제 범위 안에서 해결할 문제를 자유롭게 정할 수 있습니다.
  - 예시: 기업·산업 동향 기반 투자 리서치, 경쟁사·Peer Group 비교 분석, 내부 문서·규정 검색 및 업무 자동화
- **목표:** 단순 질의응답 챗봇이 아닌 Agent 서비스입니다. 사용자의 목적을 이해하고, 정보를 찾아 분석하고, 도구를 활용해 결과물까지 만들어야 합니다.
- **참가:** 누구나 가능합니다. 개인 또는 팀(최대 5인)으로 참가하며 중복 참가는 안 됩니다.

## 제출물

### 예선: AI Agent 기획서

- 제공 양식으로 작성해 PDF로 제출하며, 10페이지 이내여야 합니다.
- 필수 구성: summary 페이지, 문제 정의, 서비스 제안, AI Agent 구성, 데이터 활용 계획, MVP 개발 계획, 기대 효과

### 본선

- (필수) 실행 가능한 데모 URL
- (필수) 발표자료 PDF (PPT 불가, 10분 분량, 본선 평가 항목을 모두 포함)
- (필수) GitHub 실행 코드 (실행 방법·사용 기술 포함, 필요 시 zip 추가)
- (선택) 시연 영상 YouTube 링크 (가산점 있음)

## 평가 기준

### 예선: 전문가 평가 70% + 참가팀 상호 평가 30%

| 항목 | 배점 |
|---|---|
| 문제 정의 및 주제 적합성 | 20 |
| **AI Agent 구성 및 설계** (역할, Workflow, Tool/API, 자율성) | **25** |
| 차별성 및 창의성 | 20 |
| 실현 가능성 (본선 기간 안에 MVP 구현 가능 여부) | 20 |
| 활용성 및 확장성 | 15 |

- 상호 평가는 두 기획서를 비교해 더 나은 쪽에 투표하는 방식(Elo)입니다.
- 최소 투표 횟수를 채우지 못하면 우리 팀 득표도 반영되지 않습니다(No Vote, No Gain).

### 본선: 전문가 평가 100%

| 항목 | 배점 |
|---|---|
| 문제 해결 및 활용 가치 | 20 |
| **AI Agent 구현 완성도** | **25** |
| AI Agent 기술성 (단순 LLM 호출 이상의 구조) | 20 |
| 결과의 신뢰성 (근거·출처 확인, 환각 대응) | 15 |
| 사용성 및 실용성 | 10 |
| 발표 및 질의응답 | 10 |

동점 시 ① 구현 완성도 ② 문제 해결 및 활용 가치 ③ 기술성 순으로 우선합니다.

## 주요 규칙

- **데이터셋은 제공되지 않습니다.** 공개 데이터나 적법한 외부 API를 직접 골라 써야 합니다.
- 제출물에 데이터의 **출처, 수집일, 라이선스, 전처리 방법을 반드시 적어야** 합니다.
- 외부 데이터와 유료·무료 AI 모델·API를 모두 쓸 수 있습니다. 사용한 외부 자원은 출처를 밝혀야 합니다.
- 기존 공개·상용 결과물이나 다른 공모전 수상작을 그대로 낼 수 없습니다.
- 운영진이 코드 실행, API 이용 내역, 저장소 이력 등을 요청할 수 있습니다.
- 최종 제출은 팀장만 할 수 있습니다. 팀빌딩 페이지로 팀을 꾸렸다면, 제출 전에 팀장이 "팀으로 전환"을 눌러야 합니다.
